## Drafts (only the ones picked)

Load the voice skill first if there is one. Short sentences, no em dashes, clean links. Check every fact before writing it: dates from the offer page, never invent a discount code (write [CODE] if unsure).
- **Reply:** answer their exact question first, one link at most, one next step.
- **Follow-up 1:** a short nudge plus one useful thing. **Follow-up 2:** one new fact. **Follow-up 3:** close the loop, door open, say it is the last one.
- **Email:** with an email connector, a draft replying to the latest real message (not a tracking notice), same recipients and cc. Without one, the text in the reply, ready to paste.
- **LinkedIn:** text in the reply, ready to paste.
- Links: from "Links for drafts" in settings only.
